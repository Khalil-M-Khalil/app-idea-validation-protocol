# Security Policy

## 1. Scope & Applicability

The **App Idea Validation Protocol** is primarily a documentation framework, research methodology, and Claude Skill definition. It contains no executable binary dependencies, servers, or cloud infrastructure.

However, security remains paramount regarding:
- Preventing accidental leaks of API keys, access tokens, or private credentials in validation scripts or prompt examples.
- Ensuring instructions and AI prompts promote safe, privacy-conscious data practices (e.g., zero unauthorized scraping of personal data, adherence to store privacy policies).

---

## 2. Reporting a Vulnerability

If you discover any security concern, credential exposure, or prompt-injection vulnerability within this repository:

1. **Do Not Open a Public Issue:** Please do not file public GitHub issues for security vulnerabilities.
2. **Contact the Maintainer:** Submit a private advisory through GitHub's Security Advisories tab, or reach out directly to the maintainer via GitHub profile contact: [@Khalil-M-Khalil](https://github.com/Khalil-M-Khalil).
3. **Response Timeline:** We aim to acknowledge reports within 48 hours and coordinate a remediated patch or documentation correction promptly.
